# HH.uz Vacancy Notification Bot

Telegram бот для отслеживания вакансий с **двумя параллельными потоками**:
1. 🇺🇿 **Узбекистан** — локальные вакансии с hh.uz.
2. 🌐 **НОВАЯ УДАЛЕНКА** — удаленная работа со всего мира (hh.ru, schedule=remote, исключая Узбекистан).

Стек поиска строго ограничен: Flutter, Dart, Mobile, AI, LLM, React, Next.js, Frontend, Fullstack.

## Возможности

- 🔍 Автоматический поиск новых вакансий каждые 5 минут
- 📱 Мгновенные уведомления в Telegram
- 👥 Поддержка множества пользователей
- 🛡️ Трёхуровневая защита от спама (блоклист, backfill-детекция, фильтр по ключевым словам)
- 🐳 Запуск в Docker

## Команды бота

| Команда | Описание |
|---------|----------|
| `/start` | Подписаться на уведомления |
| `/stop` | Отписаться от уведомлений |
| `/status` | Показать статистику бота |

## Защита от спама

При пустых результатах API hh.ru возвращает нерелевантные вакансии. Бот фильтрует их на трёх уровнях:

1. **Блоклист заголовков** — мгновенно отклоняет вакансии «водитель», «курьер», «повар» и т.д.
2. **Backfill-детекция** — если ни одна вакансия из API-ответа не совпадает с запросом в заголовке, весь пакет считается «мусором» и проходит строгую фильтрацию.
3. **Фильтр по ключевым словам** — только вакансии, содержащие технологии из резюме (Flutter, React, Python, FastAPI, Docker и т.д.) в заголовке/описании, отправляются пользователям.

## Быстрый старт (Docker)

### 1. Создайте Telegram бота

1. Откройте [@BotFather](https://t.me/BotFather)
2. Отправьте `/newbot` и следуйте инструкциям
3. Сохраните токен бота

### 2. Запустите

```bash
# Клонируйте и настройте
cd /path/to/hh-uz-parser
cp .env.example .env
# Отредактируйте .env - укажите TELEGRAM_BOT_TOKEN

# Запустите
docker-compose up -d

# Проверьте логи
docker-compose logs -f bot
```

### 3. Подпишитесь

Отправьте `/start` вашему боту в Telegram.

## Без Docker (локально)

```bash
# PostgreSQL должен быть запущен

python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# Отредактируйте .env

python bot.py
```

## Настройка

| Переменная | Описание | По умолчанию |
|------------|----------|--------------|
| `TELEGRAM_BOT_TOKEN` | Токен бота | - |
| `CHECK_INTERVAL` | Интервал проверки (сек) | 300 |
| `DATABASE_URL` | URL PostgreSQL | postgresql://postgres:postgres@localhost:5432/hh_bot |

## Изменение позиций

Редактируйте `config.py` — три списка контролируют поведение:

- `SEARCH_QUERIES` — что искать
- `RELEVANT_KEYWORDS` — какие слова считать релевантными
- `SPAM_TITLE_BLOCKLIST` — какие заголовки сразу отклонять
